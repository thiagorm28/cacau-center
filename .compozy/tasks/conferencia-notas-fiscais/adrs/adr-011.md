# ADR-011: Deploy em VPS próprio via Docker Compose com reverse proxy TLS

## Status

Accepted

## Date

2026-08-16

## Context

Um PWA instalável com acesso à câmera exige HTTPS (exceto em `localhost`). O usuário
confirmou que o produto vai rodar em um VPS/cloud próprio com domínio, e não em um
provedor de PWA hosting gerenciado. O projeto já usa Docker Compose para orquestração
local (`new-bounded-context-scaffold`), então a topologia de produção deve reaproveitar
esse mesmo modelo em vez de introduzir uma ferramenta de deploy nova.

## Decision

Produção roda via Docker Compose num VPS: um container para `backend` (NestJS, porta
interna 3000), um container para servir o build estático do `frontend` (PWA), um
container Postgres, e um reverse proxy (Caddy) na frente dos dois, responsável por
TLS automático via Let's Encrypt e por rotear `/api/*` para o backend e o restante para
o build estático do frontend. O ambiente de desenvolvimento local continua usando as
portas já fixadas pelo `playwright.config.ts` (backend `3001`, frontend `5174`) sem
TLS, já que testes E2E rodam contra `localhost` (isento da exigência de HTTPS para
Service Worker/instalação de PWA).

## Alternatives Considered

### Alternative 1: Plataforma de hosting gerenciada (ex: Vercel/Railway/Fly.io)

- **Description**: Usar uma plataforma gerenciada de deploy em vez de um VPS próprio.
- **Pros**: TLS e infraestrutura gerenciados automaticamente, menos operação manual.
- **Cons**: Foge do modelo que o usuário já decidiu adotar (VPS/cloud próprio com
  domínio); introduz dependência de uma plataforma terceira não mencionada pelo usuário.
- **Why rejected**: O usuário confirmou explicitamente VPS/cloud próprio como direção.

## Consequences

### Positive

- Reaproveita o modelo de Docker Compose já convencionado no projeto, sem ferramenta
  nova de deploy.
- TLS automático via Caddy reduz a complexidade operacional de configurar
  certificados manualmente.

### Negative

- Requer operação manual do VPS (atualizações de SO, backups do Postgres) que uma
  plataforma gerenciada abstrairia.

### Risks

- Risco: a API interna da Cacau Show
  (`http://hybrisreports.cacaushow.com.br/ConsultaNotaFiscal/GerarXML`) pode estar
  acessível apenas de dentro da rede corporativa da Cacau Show (VPN/rede interna); se o
  VPS não conseguir alcançá-la pela internet pública, a integração (Core Feature 1)
  fica bloqueada. Mitigação: validar conectividade do VPS escolhido com esse endpoint
  antes de finalizar a escolha do provedor — registrado também como Open Question no
  TechSpec.
